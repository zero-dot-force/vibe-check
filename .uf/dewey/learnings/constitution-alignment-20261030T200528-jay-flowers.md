When a spec mandates approximate metrics, close the constitution's approximation escape hatch (documented + justified + opt-in) explicitly in the proposal's constitution-alignment table: name every approximated metric — including derived values like cycle membership computed from approximate edges, not just directly-sourced metrics — and cite the opt-in mechanism (e.g., separate tool installation). The alignment table is the artifact the planning-phase Constitution Check reads; a deviation disclosed only in design decisions and warning contracts leaves the compliance gate with an incomplete deviation inventory.
