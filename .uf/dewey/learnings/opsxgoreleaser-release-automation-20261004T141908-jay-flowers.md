When the constitution alignment table in an OpenSpec proposal references principle names that do not match the actual constitution, it causes cascading CRITICAL findings across multiple Divisor reviewers (Architect, Guard, Adversary, Entropy Divisor). Always read the actual constitution at .specify/memory/constitution.md before writing the alignment table. The correct principles are: I. Autonomous Collaboration, II. Composability First, III. Observable Quality, IV. Testability, V. Security by Default, VI. Metric Fidelity, VII. Language Agnosticism.
